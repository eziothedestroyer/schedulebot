# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability or exposed credential. Use
GitHub's **Security → Report a vulnerability** flow for this repository. Include the
affected version, reproduction steps, and impact. Do not include real access tokens,
API keys, passwords, webhook URLs, or personal schedule data.

## Supported versions

Security fixes are provided for the newest public release. Users should replace older
builds when a newer release is published and revoke any credential they believe was
exposed.
