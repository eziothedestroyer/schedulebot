Privacy Policy

Effective: September 1, 2026

Overview

ScheduleBot is a desktop creator-planning application. Schedule data and preferences are stored locally on the user's device.

Connected services

When a user chooses to connect a platform such as Discord, YouTube, Twitch, TikTok, Instagram, or OBS, ScheduleBot processes only the information needed for features the user requests. Platform access is governed by the permissions shown during authorization.

Credentials

ScheduleBot stores supported credentials in the operating system credential vault or user-protected local storage. Credentials are not bundled with public downloads or intentionally transmitted to the ScheduleBot developer.

Data sharing

ScheduleBot sends content to a connected platform only when directed by the user. It does not sell personal information or use it for advertising.

Retention and deletion

Users can remove ScheduleBot's local data and revoke connected-platform access through each platform's account settings.
